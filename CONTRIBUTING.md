# Contributing

This is a personal project. The author writes and maintains the code alone,
and pull requests are not accepted — a working program is easy to break, and
every change has to be tested across several desktops and distributions.

That said, feedback is genuinely useful.

## Bug reports

Open an issue and include:

- Your distribution and version.
- X11 or Wayland, and which desktop (GNOME, KDE, other).
- What you did, what you expected, and what happened instead.
- Any output from the console menu.

A short, reproducible description is worth more than a long one.

## Feature ideas

Open an issue describing the problem you want solved rather than the
solution you have in mind. Not every idea will be implemented, but every
one is read.

## Translations and documentation

Corrections to the manuals and the README are welcome. Open an issue with
the wording you suggest and the file it belongs to.
