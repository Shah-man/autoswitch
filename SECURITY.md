# Security Policy

## Supported versions

Only the latest release receives security fixes. When a new version comes
out, earlier ones are no longer updated.

## Reporting a vulnerability

Please open an issue in this repository. Do not include technical details of
the vulnerability in the first message — just say that you have found a
security problem and how to reach you. The details are then discussed
privately.

You can expect a reply within a few days.

## Scope

This program runs as a user process and reads keyboard input. It never
converts or logs passwords, and it writes no keystrokes to disk. Reports
about password handling, the polkit rules and the installer are especially
welcome.
